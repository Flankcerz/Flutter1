# Практична робота 3: Hello World in Flutter (Developer Card)

Цей проєкт є навчальним застосунком-візитівкою розробника, виконаним на фреймворку Flutter із використанням мови Dart. Застосунок має модульну структуру та підтримує динамічне перемикання світлої і темної тем.

---

## 🚀 Інструкція із запуску

### Передумови
* Встановлений [Flutter SDK](https://docs.flutter.dev/get-started/install)
* Встановлений [VS Code](https://code.visualstudio.com/) з розширеннями Flutter та Dart
* Браузер Google Chrome
